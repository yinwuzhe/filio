# Folio

一款用于 macOS 和 Android 的本地优先 RSS / Atom 阅读器。React 界面分别运行于 Electron 桌面容器和 Capacitor Android 容器，无需账号；两端数据相互独立，当前不提供跨端同步。

## 运行

需要 Node.js 24 LTS（版本见 `.nvmrc`）或 Node.js 22.12+，以及 npm。

- 安装依赖：`npm ci`
- 浏览器开发预览：`npm run dev`，打开 `http://127.0.0.1:5173`
- 启动桌面应用：`npm run desktop`
- 桌面热更新开发：`npm run desktop:dev`（请先关闭独立运行的 Vite，避免端口占用）
- 构建前端：`npm run build`
- 运行全部测试：`npm test`
- 构建 macOS DMG：`npm run package:mac`，产物位于 `release/`

默认构建本机架构。跨架构构建可运行 `npm run package:mac -- --x64` 或 `--arm64`。公开分发需要自行配置 Apple Developer 签名和公证；本项目不包含证书。

## Android 独立手机版

手机端和 macOS **不进行同步**。订阅、阅读记录、收藏、译文、翻译 API 配置分别保存在各自设备；手机无需连接电脑即可拉取 RSS 和翻译文章。

- 安装包：`release/Folio-1.0.2-android-debug.apk`（本机调试签名的独立体验版，并非应用商店正式发行版）。1.0.2 修复手机自动填充导致订阅地址误判的问题；可输入 `github.blog/feed/`，未填写协议时自动使用 HTTPS。
- 将 APK 传到手机，用文件管理器打开，根据 Android 提示允许该来源安装应用。需要 Android 7.0 / API 24 或更新系统以及可用的 Android System WebView；推荐更新 WebView。
- 左上角菜单管理订阅；点文章进入正文。系统返回手势先关闭弹窗/菜单，再回文章列表；在列表根页面返回会将应用置于后台。
- 离线阅读保存的文章和译文；正文远程图片仍需联网。前台按配置定时刷新，回到前台检查过期订阅；没有常驻后台服务或关闭应用后的定时任务。
- 翻译设置与电脑分开配置，密钥由 Android Keystore + AES-GCM 加密保存在不参与备份的私有目录。只在主动点击翻译时发送文字给配置的 API 服务商。
- Android 的文章导出使用系统分享面板。应用只声明联网权限，不申请通讯录、定位或共享文件存储权限；自动云备份及设备迁移已禁用。
- 卸载或清除应用数据会删除手机阅读库。保留本机调试签名密钥，后续版本才能直接覆盖安装；更换签名通常需要先卸载，会丢失本机数据。

### Android 开发与验证

需要 Node.js 24、JDK 21（可使用 Android Studio 自带的 JBR）、Android SDK Platform 36 和相应 Build Tools。设置 `JAVA_HOME`，并通过 `ANDROID_HOME` 或 `android/local.properties` 指定 SDK。不要提交该机器配置文件。

- `npm run android:apk`：构建 Web 资源、同步到手机工程并生成 `android/app/build/outputs/apk/debug/app-debug.apk`。
- `npm run android:open`：在 Android Studio 打开工程。
- `npm run android:run`：安装到已连接手机或模拟器。
- `npm run android:test`：原生 RSS、安全网络与翻译单元测试。
- `cd android && ./gradlew connectedDebugAndroidTest`：在已连接设备上验证 Android XML 解析栈与真实 Keystore 加密。
- `npm test`：原有 Web/macOS 功能和 Android 桥接的回归测试。

正式发布需自行配置发布签名并生成 release APK/AAB。调试包允许经 ADB 检查 WebView；release 构建禁用这项调试功能。

## 功能

- 多 RSS / Atom 订阅、分类浏览、订阅移除确认及单源/全量刷新。
- 5、15、30、60 分钟自动刷新或手动模式。定时更新在窗口运行时执行，重新激活时检查过期订阅。
- 全部、未读、收藏、今日文章视图，搜索与时间排序。
- 已读/未读切换、批量标记已读、收藏，更新后保留文章状态。
- 正文阅读、字号、浅色/深色/跟随系统、专注模式、文本导出及系统浏览器打开原文。
- IndexedDB 持久化订阅、文章内容、阅读状态及设置。桌面应用资源与字体内置，可离线启动阅读。

首次启动包含明确标注的原创示例文章，仅用于体验界面，不是对应媒体发布的真实文章。点击刷新会获取真实订阅内容并替换该源未收藏的示例文章。也可以删除默认源并添加自己的 RSS / Atom URL。

## 英文文章翻译

正文工具栏提供 **翻译为中文 / 显示原文** 按钮。首次使用会打开翻译设置，也可通过 **Settings → 文章翻译 · 配置 API** 修改。

1. 填写支持 Chat Completions 的 OpenAI 兼容服务的 API Base URL、模型 ID 和 API Key。默认基础地址为 `https://api.openai.com/v1`；模型需使用服务商实际支持的 ID。
2. 确认文字发送说明并保存。仅支持公网 HTTPS 基础地址，系统自动追加 `/chat/completions`。
3. 关闭设置，点击 **翻译为中文**。成功后标题、摘要和正文在应用内显示中文；点击 **显示原文** 可立即切回。

- 仅点击翻译时向所配置服务发送文章文字，可能产生 API 费用；不会自动翻译订阅源。图片、链接目标和代码块不发送，排版及代码保留。
- 单篇最多 40,000 字符，超过限制会明确提示，不会偷偷截取部分文章。可取消，切换文章或原文更新也会取消；失败保留原文，只有完整译文会缓存。
- 译文单独保存在本机，已读和收藏不受影响；可离线切换，刷新相同内容时保留，原文改变后失效。搜索和文本导出仍使用原文。
- 桌面版使用 Electron `safeStorage` 与 macOS 钥匙串保护的加密文件保存 API 配置，不在文章库中保存密钥。未签名应用更新后可能再次请求钥匙串访问授权；无法解密时可清除设置后重新填写。
- 浏览器开发预览仅在本地服务内存保存配置，重启服务即丢失。更改服务地址必须重新输入密钥，防止旧密钥发送给新服务。
- 服务地址和密钥由用户自己配置；没有预置额度或共享密钥。自动化测试使用模拟翻译响应，不代表已验证某个用户账户或服务商的实际翻译效果。

## 离线与安全边界

- 离线保存的是订阅源提供的正文/摘要；若源仅提供摘要，不会绕过原站限制获取全文。
- 远程文章图片需要联网。内置示例图片和全部字体随桌面应用打包。
- 浏览器预览需要本地 Vite 服务；完整断网冷启动由打包后的桌面应用提供。
- 文章 HTML 使用 DOMPurify 清理；Electron 禁用 Node 集成并启用沙箱与上下文隔离。
- 订阅只支持公共 HTTP(S) URL，拒绝本地/私有网络、嵌入凭据和非网页协议。逐次校验重定向并固定已验证 DNS 地址。
- 每次请求最多 20 秒、5 次重定向、8 MB 原始/解压响应、1000 条文章，失败不会清空旧内容。
- 阅读库保存在当前设备，不进行云同步；主动翻译时文章文字会发送给用户配置的服务商，其处理与留存规则由该服务商决定。卸载时若同时清理应用数据，文章与阅读状态会一并删除。

## 工程

- `src/`：界面、阅读状态、本地缓存及前端测试。
- `server/feeds.mjs`：RSS / Atom 拉取、解析与开发预览 API。
- `electron/`：桌面窗口、安全配置和窄接口 IPC。
- `server/feeds.test.mjs`：RSS、安全边界及桌面行为测试。
- `public/images/`：来自 Unsplash 的示例配图；UI 字体为随包分发的 DM Sans 与 Lora（Fontsource）。
